# Getting Started

<Lead>iOS Mail-style swipe actions for list rows.</Lead>

Swipe partway to reveal a row's actions, or all the way to commit the main one. A vertical drag still scrolls the page, a quick flick opens a row even over a short distance, and only one row is open at a time.

## Create a row

Compose the parts. Each side's actions stay hidden until the row is swiped that way.

<CodeFile name="mail-row.tsx">

```tsx
import * as Sidle from "sidle/react";

export function MailRow({ mail, onArchive, onDelete }) {
	return (
		<Sidle.Row value={mail.id}>
			<Sidle.Actions side="start">
				<Sidle.Action onSelect={onArchive}>Archive</Sidle.Action>
			</Sidle.Actions>
			<Sidle.Content>{mail.subject}</Sidle.Content>
			<Sidle.Actions side="end">
				<Sidle.Action onSelect={onDelete} commit>
					Delete
				</Sidle.Action>
			</Sidle.Actions>
		</Sidle.Row>
	);
}
```

</CodeFile>

## Style it

sidle ships no CSS. Style the parts with your own classes, and the motion takes care of itself.

```tsx
<Sidle.Content className="bg-white px-4 py-3">{/* ... */}</Sidle.Content>
<Sidle.Action className="bg-red-500 text-white" onSelect={remove} commit>
	Delete
</Sidle.Action>
```

Give `Sidle.Content` a background of its own. Don't set `transform` on it or `width` on `Sidle.Actions`, as those move every frame.
