# Styling

<Lead>The same parts, in any look.</Lead>

sidle ships no CSS. Each part takes your own classes, and sets only the inline styles swiping depends on. Here's one list in five styles.

## Site

The look of this site. The actions sit a shade off the row, so they read as one surface.

<Example name="style-site" />

## Glass

A translucent fill with `backdrop-blur` on the list. Actions only fill the gap the row opens, so they don't show through.

<Example name="style-glass" />

## Neobrutalist

Thick borders and a hard offset shadow. The shadow goes on the list, as rows clip their own overflow.

<Example name="style-brutalist" />

## Terminal

Monospace and sharp corners. An action's children can be anything.

<Example name="style-terminal" />

## Soft

Large radii and a wide, diffuse shadow, one per row. A rounded `Sidle.Row` clips its actions to match.

<Example name="style-soft" />

## Style by state

`Sidle.Row` has a `data-phase`, and `Sidle.Actions` has a `data-armed` when letting go would commit.

```tsx
<Sidle.Row className="data-[phase=dragging]:shadow-lg">
	<Sidle.Actions side="end" className="group">
		<Sidle.Action className="bg-neutral-400 group-data-armed:bg-red-500" />
	</Sidle.Actions>
</Sidle.Row>
```

## Good to know

- Give `Sidle.Content` a background of its own, or the page shows through as it moves.
- Don't set `transform` on `Sidle.Content` or `width` on `Sidle.Actions`. Both change every frame.
- Set a panel's size with the `width` prop instead.
